## Описание

«Зерно&Co» — учебный интернет-магазин кофе в зёрнах на Bootstrap 5.3.8. Это отдельная реализация предметной области, а не адаптация КР №1.

## Используемый фреймворк и подключение

Bootstrap 5.3.8. Подключение: **CDN** (jsDelivr). Собственный `css/custom.css` подключён после Bootstrap.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html      # главная: hero, преимущества, популярные товары
├── catalog.html    # каталог: карточки, фильтр по обжарке, пагинация, модальное окно
├── product.html    # товар: карусель, вкладки, таблица, accordion
├── order.html      # форма заявки с валидацией и toast
├── css/custom.css  # тема кофейных цветов и мелкие правки
├── images/
├── README.md
└── .gitignore
```

## Реализованные компоненты

`navbar` (+dropdown), `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `carousel`, `nav-tabs`, `nav-pills`, `pagination`, `toast`, `breadcrumb`, `table-responsive`.

## Самостоятельные доработки

- Кофейная тема через CSS-переменные Bootstrap (`--bs-primary`, `--bs-btn-*`) без переписывания компонентов.
- Фильтр каталога по обжарке (небольшой JS, переключение `d-none`).
- Заявка: выбор помола и количества, валидация Bootstrap (`was-validated`), уведомление `toast`.
- Предвыбор товара в форме через параметр `?product=` из ссылки на странице товара.
- Страница товара: карусель, вкладки, accordion с вопросами.
- Видимое состояние фокуса для клавиатурной навигации.

## Как проверить

1. Открыть `index.html`, проверить навигацию на всех страницах.
2. `catalog.html`: фильтр, кнопка «Заказать» открывает модальное окно.
3. `product.html`: карусель, вкладки, accordion.
4. `order.html`: отправить пустую форму (ошибки), затем заполненную (toast).
5. Проверить адаптивность в DevTools: 375 / 768 / 1024 / 1440 px.
